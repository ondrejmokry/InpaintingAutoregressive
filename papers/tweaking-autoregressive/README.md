# Tweaking autoregressive methods for inpainting of gaps in audio signals

Ondřej Mokrý and Pavel Rajmic, presented at EUSIPCO 2025.

The preprint is available at [arXiv](http://arxiv.org/abs/2403.04433); the official version is published at [IEEE Xplore](https://ieeexplore.ieee.org/document/11226154).

This folder contains the paper-specific MATLAB runners, plotting scripts, and result files. Shared data and dependencies are kept at the repository root.

- `maintest.m` runs the AR-based experiments.
- `maintest_spain.m` runs the SPAIN reference experiments.
- `plotting/` contains scripts for reproducing the figures.
- `results/` contains the precomputed result tables.
